2. ABSTRACT AND PROBLEM STATEMENT
---------------------------------
Abstract:
Fast fashion has increased clothing consumption and textile waste, while many people own wearable clothes they no longer use but find hard to sell or donate. LoopWear is a web marketplace that lets users list unused clothes, browse items from other users, send swap requests, negotiate through chat, and agree on a fair exchange using an estimated swap value. The platform supports location-based matching and an admin panel for moderation and dispute handling. The system is built with React on the front end, Node.js and Express on the back end, and MongoDB for data, and is deployed on Vercel.

Problem statement (from the project brief):
- Many people have unused clothes but no easy way to exchange them
- Traditional e-commerce platforms focus only on buying and selling
- Resale platforms can involve complicated pricing
- There are few platforms dedicated to clothing swapping
- Sustainable fashion options are limited for many users

The brief names Depop, Poshmark and Swap.com as reference platforms; LoopWear differs by removing money from the transaction and using direct barter.


3. OBJECTIVES AND SCOPE
-----------------------
Primary objectives:
- Provide a marketplace dedicated to clothing exchange
- Let users swap clothes directly without money changing hands
- Encourage sustainable fashion practices
- Provide location-based swap matching

Secondary objectives:
- Enable negotiation between users before a swap is final
- Calculate an estimated swap value
- Filter clothes by category and location
- Offer courier integration for remote swaps (optional)
- Build a community around sustainable fashion

In scope (Phase 1): user registration and login; clothing listing system; swap request system; negotiation chat; swap value calculator; location-based swap suggestions; admin management panel.
Out of scope (Phase 1): online payments; AI fashion recommendations; AR virtual try-on; mobile application.

7. DEPLOYMENT, LEARNINGS AND CONCLUSION
---------------------------------------
Deployment:
The app is deployed on Vercel at https://loopwear-eight.vercel.app. The root build script builds the client (cd client && npm run build) and start runs the server (cd server && npm start). Production needs a MONGODB_URI environment variable, because Vercel functions are ephemeral and an in-memory store loses data on every restart.

Key performance indicators:
- Number of clothing listings : items uploaded by users
- Successful swaps            : requests that reached an accepted, completed state
- Swap request conversion rate: accepted requests / sent requests x 100
- User engagement rate        : users who list, request or chat / registered users x 100
- Active users                : users with activity in the last 30 days

Challenges and solutions:
- Fair swaps between different items -> swap value calculator (brand, condition, category) plus chat negotiation
- Data lost on serverless hosting -> MongoDB as the production database
- Insecure first version (found in review) -> password hashing, JWT, Helmet, rate limiting, CORS rules, validation
- Matching users by place -> location field on users and listings, with filter and nearby suggestions

Skills learned:
- Building a full-stack app with React, Express and MongoDB
- Designing REST APIs, roles and a swap workflow with statuses
- Securing an app: hashing, JWT, rate limiting, validation, headers
- Deploying to Vercel and managing environment variables
- Using Git and GitHub, and reviewing code against a checklist

Future scope:
- AI-based swap recommendations
- Mobile application
- Clothing condition verification
- Sustainability impact tracker (waste saved)
- Community fashion groups
- Courier integration and online payments for shipping costs

Conclusion:
LoopWear delivers a working, deployed clothing swap marketplace with listings, swap requests, negotiation chat, value estimates, location matching and an admin panel, and it supports the goals of reusing clothes and cutting textile waste. Future phases can add recommendations, a mobile app and an impact tracker.
